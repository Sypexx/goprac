## Что это

Приложение для фиксации измерений в коровниках: показатели микроклимата и животных,
отчётность, инвентаризация. Ключевые требования: **RFID-метки** и **оффлайн-режим с выгрузкой**.

## Стек

- **Frontend:** `frontend/` — Vite + React 19 + TypeScript. Dev на `:5173`, прокси `/api` → `:8080`
- **Backend:** `backend/` — Go (net/http, роутинг Go 1.22+ с параметрами путей), драйвер `pgx/v5`
- **БД:** PostgreSQL 18, локальная, служба `postgresql-x64-18`. Подключение через `backend/.env`
  (переменная `DATABASE_URL`, шаблон в `backend/.env.example`, пароль НЕ в git)
- **Git:** https://github.com/Sypexx/goprac, ветка main

## Запуск

```bash
cd backend && go run .      # терминал 1 — API + статика на :8080
cd frontend && npm run dev  # терминал 2 — dev-сервер на :5173
```

Открывать `http://localhost:5173` (dev) или `:8080` (прод-сборка из `frontend/dist`).

## Схема БД (MVP реализован)

Миграции идемпотентны, применяются при старте сервера: `schema.sql` → `seed.sql` → `comments.sql`
(пакет `backend/db`, embed). Комментарии к таблицам видны в DBeaver/pgAdmin.

- `users` — сотрудники (оператор, зоотехник)
- `group_types`, `groups` — типы групп (Коровники, Склады) и иерархия групп
- `object_types` — типы объектов (Коровник/Животное/Инвентарь), флаг `group_flag`
- `objects` — **единый реестр экземпляров** (решение: одна таблица + FK вместо «таблица на тип»)
- `object_identifiers` — RFID/бирки/чипы (у объекта может быть несколько, UNIQUE по типу+значению)
- `object_groups` (m:n), `object_history` — принадлежность группам и аудит перемещений
- `measures` — показатели (Температура/Влажность/Вес/Надой), тип **instant/balance**
- `measure_to_object_type` — какие показатели у какого типа объектов
- `measure_values` — сырые измерения. **`client_uuid UNIQUE` = идемпотентная оффлайн-синхронизация**
  (повторная отправка не создаёт дубль, `ON CONFLICT DO NOTHING`)

Сиды: 2 коровника, 3 коровы (Зорька, Бурёнка, Милка) с бирками `TAG-*`, показатели привязаны к типам.

## API

- `GET /api/health`
- `GET /api/groups` — список групп
- `GET /api/objects?group_id=` — объекты группы (с биркой)
- `GET /api/measures?object_type_id=` — показатели типа объекта
- `GET /api/measure-values?object_id=` — последние 50 измерений объекта
- `POST /api/measure-values` — одно значение `{client_uuid, measure_id, object_id, value, measured_at, device_id}`
- `POST /api/sync` — пакетная выгрузка `{values: [...]}` → `{inserted, skipped}` (skipped = дубли по uuid)

## Фронтенд

`frontend/src/App.tsx` — один экран: сайдбар групп → список объектов группы → карточка объекта
(ввод измерения + история). Оффлайн: записи копятся в `localStorage` (ключ `offline_queue`),
при появлении сети автосинхронизация на `/api/sync`, статус онлайн/оффлайн в шапке.
